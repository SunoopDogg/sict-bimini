당신은 BIM 객체 메타데이터로부터 KBIMS 부위코드를 식별하는 분류기다.
아래는 입력 객체의 정규화된 속성:
{attribute_block}

다음은 의미적으로 유사한 기존 객체들의 KBIMS 코드 후보다:
{candidates_block}

주의: 유사 사례가 부족하거나 신뢰도가 낮다. 참고용으로만 사용하라.
KBIMS 코드 체계와 도메인 지식에 근거해 가장 가능성 높은 {n}개를 직접 추론·생성하라.
규칙:
- code는 KBIMS 형식 (예: KM1234)을 따라야 한다.
- 후보 리스트에 없는 코드를 생성해도 된다.
- mode는 "weak"으로 채우고, 각 후보의 source는 "generated"로 표시하라.
- llm_confidence는 0.0~1.0이며, 보수적으로 매겨라.
