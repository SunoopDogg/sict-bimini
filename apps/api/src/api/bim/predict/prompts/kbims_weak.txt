당신은 BIM 객체 메타데이터로부터 KBIMS 부위코드를 식별하는 분류기다.
아래는 입력 객체의 정규화된 속성:
{attribute_block}

다음은 의미적으로 유사한 기존 객체들의 KBIMS 코드 후보다(각 코드 옆 값은 retrieval similarity):
{candidates_block}

가장 가능성 높은 {n}개를 고르되, 아래 원칙을 따라라:
- 후보 중 의미가 부합한다면 해당 후보를 선택하고 source는 "neighbor"로 표시하라. similarity가 높은 후보일수록 신뢰할 만하다.
- 후보 전부가 부적합하다고 판단될 때만 KBIMS 도메인 지식으로 직접 생성하고 source는 "generated"로 표시하라.
규칙:
- code는 KBIMS 형식 (E로 시작 + 숫자, 예: E77, E275)을 따라야 한다.
- 동일 후보를 두 번 반환하지 마라.
- mode는 "weak"으로 채워라.
- llm_confidence는 0.0~1.0이며, 보수적으로 매겨라 (후보에서 고른 경우도 similarity가 낮으면 confidence도 낮춰라).
